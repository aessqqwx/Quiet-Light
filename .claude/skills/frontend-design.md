# Frontend Design Skill

Этот скилл покрывает базовые принципы фронтенд‑дизайна: семантическая разметка, CSS‑переменные, адаптивные сетки, доступность (ARIA) и стили для печати. В проекте все рекомендации реализованы напрямую в `style.css` и `index.html`. Поскольку проект работает без сборщиков, подключение происходит через CDN и локальные стили, а не через отдельные файлы скилла.
